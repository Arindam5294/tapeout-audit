Key news

Existing processors can no longer be changed by anyone.

Every hour the whole protocol is re-read at one pinned block. Read-only: no keys, no writes to chain.

Oct 22, 2026

TapeOut froze all processors. Both processor beacons were renounced (owner = 0x0), so nobody can change the code of existing processors.

The factory moved to the new audited implementation (pinned by TapeKit). The factory itself is not sealed yet, so its owner can still change how new processors are made.

How it works

Four steps, every hour, and anyone can re-check the result.

01

Pin

Pin one block from two operators

    02

    Read

    About 13,000 multicall reads, compared

      Every contract read is made against both operators at the pinned block, and each section is compared by SHA-256.

      03

      Check

      Run 16 integrity checks

        Audited code versions, owners and admin keys, genuine processors, append-only numbering, container ownership, website file fingerprints, payments and event history.

        04

        Seal

        Sign with Ed25519, timestamp on Bitcoin

          The report is signed with Ed25519 and timestamped on Bitcoin with OpenTimestamps, so it cannot be backdated or quietly edited.
